# 2026-10-22

## Added

- 新增 Gin HTTP、类型化环境配置、Zap 日志、sqlx 数据访问、Goose 管理库迁移和 Cobra 命令行；无参数只显示帮助。
- 实现新管理库的管理员初始化、角色权限、Argon2id 密码、数据库会话、CSRF、登录限流及审计；改密或停用使原会话失效。
- 实现游戏账号注册、邮箱修改、改密、封禁/解禁、批量操作、角色查询及登录日志；不返回密码或游戏令牌。删除任务由服务端执行，API仅受理、查询和重试。
- 实现游戏控制适配、持久化幂等命令、在线快照及角色维护；超时或断连保留未知结果，不自动重复执行。
- 实现四类资料集原子导入、版本历史、物品/魔物/地图/NPC检索和图片；分类导出与前端共用规则，保留来源哈希。
- 实现物品邮件、背包及Zeny发放；游戏库事务回执避免跨库故障后重复发放，并与账号删除共用锁。
- 实现冒险工具的游戏令牌认证、角色归属校验、实时功能策略、共享数据库限流；复用角色和奖励用例。
- 实现30项游戏设置的校验、原子文件发布、持久化修订和恢复；地图服实例/版本及执行凭据限制过期请求，版本屏障使未执行旧请求失效后才允许新尝试。

- 建立独立 HappyRO API Go 项目，迁入管理后台与玩家 API 的业务实现和测试；迁移期间继续整理业务边界与部署路径。

## Changed


- 游戏账号管理与角色查询分别归属 accounts、characters；快照服务依赖角色查询接口。
- 地图目录与外观映射统一归属 catalog，保留生成来源与校验。
- API 原生 systemd 配置由本仓库维护。

- 冒险工具用例归入 characters 与 rewards，玩家策略和限流归入 session，复用后台相同的游戏命令与奖励校验。

- 游戏库账号唯一约束与邮件回执 SQL 统一由 happyro-server 提供；API 仅检查结构，移除游戏库 DDL 命令，数据库容器初始化直接使用服务端 SQL。

- HTTP 管理员与玩家入口拆为独立 handler 包，共享协议响应工具；玩家处理器不持有管理员会话、账号管理或后台权限依赖。

- Docker 配置归入本仓库；部署服务与镜像统一使用 api，前端产物随 API 同源交付。

- 管理员登录、会话身份校验与退出审计归入 session；identity 保留管理员账号、角色和密码管理。默认前端目录修正为独立 happyro-admin 的 dist。

- 修正原生部署的地图索引默认路径，使其指向同级 happyro-server；后端开发说明随代码移入本仓库。
